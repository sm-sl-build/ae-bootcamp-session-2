# UI Guidelines

## Overview

The application should follow a clean, modern interface that is easy to use and accessible.

## Design Principles

- Use Material UI components consistently throughout the app.
- Keep the layout simple, uncluttered, and responsive.
- Use clear spacing and readable typography.

## Visual Style

- Prefer a light background with dark text for primary content.
- Use a calm blue-based accent color for primary actions.
- Use muted gray tones for secondary surfaces and borders.

## Component Styling

- Primary buttons should use a prominent filled style.
- Secondary buttons should use an outlined style.
- Forms should include clear labels and helpful spacing.

## Accessibility

- Ensure all interactive elements are keyboard accessible.
- Maintain sufficient color contrast for text and controls.
- Provide descriptive labels for buttons and form inputs.
